# Name and file extension checks

Recorded 2026-09-26 (milestone 12; owner, prompt 56, E a). These are web
searches, not a formal clearance search and not legal advice. The
project is personal and not marketed; a formal search (for example the
USPTO's own database at https://tmsearch.uspto.gov/, which works only in
a browser and could not be queried from the agent's tools) and an IP
lawyer are worth it before any commercial use.

## What it means

- The names: nothing found blocks a personal, non-commercial open-source
  project named HyperSol HyperSpace 3D and HoloML. The closest marks
  ("HYPERSPACE" in health-care software and virtual exhibitions) are in
  other fields.
- The extension: `.holo` is not unique. Operating systems and browsers
  should not rely on the extension alone: a HoloML page is identified by
  its media type when served over the web and by its root element when
  opened from disk. The owner chose `.holoml`, which nothing else uses
  and which matches the name (prompt 63); the media type is
  `model/vnd.holoml` (HoloML SPEC.md, section 4, "Files").
