# Name and file extension checks

Recorded 2026-09-26 (milestone 12; owner, prompt 56, E a). These are web
searches, not a formal clearance search and not legal advice. The
project is personal and not marketed; a formal search (for example the
USPTO's own database at https://tmsearch.uspto.gov/, which works only in
a browser and could not be queried from the agent's tools) and an IP
lawyer are worth it before any commercial use.

## What was searched, and what came back

| Name | Searched | Found |
|---|---|---|
| HyperSpace 3D | Web search for "HyperSpace 3D" trademarks in software | No registration for "HyperSpace 3D". "HYPERSPACE" alone is registered by others for unrelated software and services: Epic Systems (health-care software user interface, reg. 2748402), Hyperreal Digital (virtual exhibitions, serial 98928893), and others; "HYPERSPACE MODELER" (3D modelling) was abandoned in 1992 |
| HyperSol | Web search for "HyperSol" trademarks at the USPTO | No registration found. HyperSol was the owner's company, founded in 2001, which no longer exists |
| HoloML | Web search for "HoloML" as a markup language or trademark | Only this project (github.com/srajpal/holoml); no trademark found |
| `.holo` | Web search for the ".holo" file extension | Already used by two formats: a digital holography data format (holofile.org, with ImageJ, MATLAB, and Python readers) and HoloBuilder project files |

## What it means

- The names: nothing found blocks a personal, non-commercial open-source
  project named HyperSol HyperSpace 3D and HoloML. The closest marks
  ("HYPERSPACE" in health-care software and virtual exhibitions) are in
  other fields.
- The extension: `.holo` is not unique. Operating systems and browsers
  should not rely on the extension alone: a HoloML page is identified by
  its media type when served over the web (to be defined in the HoloML
  spec, milestone 13) and by its root element when opened from disk.
  Choosing the extension again is an open question for milestone 13.
